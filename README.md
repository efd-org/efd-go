# efd-go

Simple Go hello-world starter project.

## Build
```bash
go build ./...
```

This compiles the package and produces an executable binary in the current directory (or build output depending on the target). For a single-file app, it typically creates an executable named `main` or `main.exe` for deployment.

## Run
```bash
go run main.go
```

Expected output:
```text
Hello, World!
```

## Test
```bash
go test ./...
```
